# Yasir Usman | Dubai Real Estate

A responsive, image-led static website for Yasir Usman. It uses plain HTML, CSS and JavaScript, with no build step, paid service, API key or backend.

## Preview locally

Open `index.html` in a browser, or start a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Update the site

- Edit copy and contact links in `index.html`.
- Adjust colors, type and layout in `css/style.css`.
- Update the slideshow, mobile menu or gallery behavior in `js/script.js`.
- Replace photography in `assets/images/` and update the matching `src` in `index.html`.
- See `assets/image-manifest.md` for the image inventory and sources.

The location and property images are editorial inspiration, not representations of live listings or confirmed photographs of each named city. Confirm actual inventory and location details directly with Yasir before publishing property-specific claims.

## Publish with GitHub Pages

1. Create a GitHub repository and add these project files.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the branch containing the site and the repository root (`/`), then save.
4. Open the URL shown by GitHub Pages after deployment completes.

All site links to local files are relative, so the page works from a repository subpath as well as a domain root.
